## Confirmed findings (details being finalized)

1. Shared DialogWindow captures Enter before focused Cancel/secondary buttons can handle it, always accepting the primary action. In library Delete captures, focus Cancel and press Enter: the capture is deleted. Unsaved-changes secondary No also becomes Yes. Focused-button Enter must retain button semantics. Add STA regression tests for Cancel and secondary button sources.
2. AnnotationPropertiesPanel NumericValue lacks getters for Horizontal padding, Vertical padding and Magnifier zoom; the fallback returns StrokeWidth. The actual padding/zoom rows therefore show and start nudges/drags from unrelated values after refresh, and cannot show mixed state based on their actual field. Test unequal padding/zoom versus StrokeWidth, then commit/undo and verify row synchronization.
3. AnnotationPropertiesPanel SegmentValue lacks Vertical and Box size mappings, defaulting both to index zero. A Middle/Bottom or Fixed/AutoHeight annotation shows Top/Fit text, and clicking another choice returns the checked state to zero after refresh. Test all text vertical/sizing values, mixed values, commit and undo.
4. Mixed slider cancellation uses a scalar Preview(startValue), applying the first value across all targets instead of clearing the preview. `SliderRow.EndGesture` canceled branch and `NumberBox.CancelScrub` have no cancellation event for panels to call EndPreview. Repro two unequal image edge or annotation widths, drag preview, cancel: displayed mixed values remain flattened until another operation clears preview. Original document and undo remain intact. Suggested regression: cancel a mixed drag/scrub and assert PreviewState null, original per-target values and unchanged undo count.
5. Library screen pin Edit callback calls `LibraryActions.Add` with the original asset ID (`LibraryActions.cs:54-55`). Deleting its unprotected library entry removes the asset (`:71-73`); the open pin keeps its bitmap but E/Open in editor silently does nothing. Retention also removes unprotected assets. Expected reopen from retained immutable pixels. Adjacent root-owned composition pin passes only ShowEditor (`MainWindow.xaml.cs:974`), so it similarly never restores the pinned pixels after the current composition changes.
6. `SubtleToggleButton` hover changes to HighlightColor without HighlightText (`Controls.xaml:208`); `ExpanderHeaderToggle` hover changes background to HighlightColor but retains WindowText and explicitly sets the chevron to WindowText (`:413`). High Contrast palettes where WindowText and HighlightText differ render hovered layout/classic segments and inspector headers illegibly. Use `Text.Selected` for text/glyphs on highlight surfaces. OS palette visual checks remain manual.
7. Inspector More > Reset tool default calls `vm.ResetDefaultStyle(_tool().ToString())` (`InspectorPanel.cs:57`) rather than selected annotation kind. Select an Arrow using Select after setting an Arrow custom default: Reset announces Select reset and leaves Arrow custom. Expected reset the kind shown by the inspector, with prototype and selection tests.
