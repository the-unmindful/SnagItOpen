# SnagItOpen product context

## Register
product

## Users
Windows users capturing, combining, annotating and sharing screenshots locally. They work in everyday desktop lighting and follow their Windows light, dark or high-contrast preference.

## Product Purpose
Move from capture to a clear shared image with few steps, while retaining editable local compositions and original assets.

## Brand Personality
Calm, precise, practical. Native Windows interaction, quiet chrome and discoverable commands.

## Anti-references
Avoid stock controls mixed with unrelated custom styling, emoji UI icons, repeated toolbars, decorative effects, packed text prompts, and permanent warning paragraphs.

## Design Principles
Content first. One visible home per control. Progressive disclosure. Immediate feedback. Respect system settings. Distinguish secure redaction from visual effects.

## Accessibility & Inclusion
Keyboard-complete operation, named automation controls, focus rings, high contrast, reduced motion, 200% text scaling and per-monitor DPI support.
